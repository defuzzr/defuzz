# tmpl-prefix

TypeScript service and command-line apps running on Node.js.

Tools: Node.js and pnpm (selected by `package.json`).
Minimum versions are in `TOOLS.lock`.

Run all checks: `pnpm xtask ci`

- Code: `packages/`.
- Tests: `*.test.ts` beside the code.
- Scripts: `.sh`, `.bash` and `.ps1` go in `scripts/` (created as needed).
