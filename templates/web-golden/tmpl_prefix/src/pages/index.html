tmpl_prefix

A small static website. Each page is plain HTML, styled by one stylesheet and built into a folder of files you can put on any web host.

What you get

  • Pages that read well on a phone, a tablet and a desktop screen.
  • A light and a dark colour theme that follow your system setting.
  • Text and controls with enough contrast in both themes.
  • Content that works with JavaScript turned off.

Where to start

Change the text of this page in src/pages/index.html. Change colours, type sizes and spacing in design/tokens/tokens.css. Read more about how this site is built.
