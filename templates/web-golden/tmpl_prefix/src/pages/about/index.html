About this site

This page explains how the site is put together, so you can change it with confidence.

Pages

Every HTML file in src/pages/ is one page. The file src/pages/about/index.html is served at the address /about/.

Shared parts

The header and footer live once in src/components/. A page includes them with a comment such as <!-- include: footer.html -->, which is replaced by the file when the site is served or built. The header marks the link to the page you are on: <!-- include: header.html current=/about/ -->.

Design tokens

Colours, fonts, type sizes and spacing are named values in design/tokens/tokens.css. The stylesheet in src/styles/ takes all of these from those names, so one change there updates the whole site.

Checks

The command pnpm xtask ci checks formatting, types and the unit tests. The tests list every colour pair the stylesheet declares, check its contrast, and fail when a rule uses colour in a way they cannot read. It then builds the site and checks the built files, including that no link points to a missing page.
