# tmpl-prefix

Python service and command-line apps with separate code layers.

Tools: Python and uv.
Versions: `TOOLS.lock`; Python's minimum: `pyproject.toml`.

Run all checks: `uv run xtask ci`

- Code: `packages/`.
- Tests: `tests/` inside packages and `tools/xtask/`.
- Scripts: `.sh`, `.bash` and `.ps1` go in `scripts/` (created as needed).
