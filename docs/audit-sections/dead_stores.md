# Dead stores and regenerable caches (`report.dead_stores`)

Measures archives, plugin folders, caches and other stored files using metadata and bounded config/manifest reads.
`BUNDLED_PLUGIN_NAMES` in `audit/dead_stores.py` is a fixed cross-release allowlist; listed names are excluded from missing-plugin findings.
The disabled-plugin check compares aggregate bytes with `DISABLED_PLUGIN_THRESHOLD_BYTES`, or reports any disabled hooks or parked copies.
Sizes are file sizes, not unique disk blocks. Section totals overlap other audit sections; they are not a deletion recommendation.

Within budgets, unchanged inputs give unchanged raw measurements. Budget cuts retain partial results with `could_not_verify` coverage.
Read scope: [audit-scope.md](../audit-scope.md). Bounds are the `MAX_*` constants in `audit/dead_stores.py`.

## Findings

| Rule id | Classification | Fires when | Consequence (exact, fixed) |
| --- | --- | --- | --- |
| `dead_stores.profile_exports` | `review_suggested` | exports + large archives > `PROFILE_EXPORTS_THRESHOLD_BYTES` | Profile export and backup archive files total more than 50 MiB; byte counts and write-time bursts measure archive files on disk and do not show whether another copy exists or whether the files are still needed. |
| `dead_stores.parked_or_disabled_plugins` | `review_suggested` | any parked copy, aggregate disabled bytes > `DISABLED_PLUGIN_THRESHOLD_BYTES`, or any disabled hooks | Plugin folders with parked-style names, or not enabled in plugins.enabled, are on disk; parked-style folder names other than .previous- are not defined by the Hermes source, and byte and declared-hook counts measure files and manifest entries and do not show whether these plugins were ever loaded. |
| `dead_stores.enabled_plugin_missing` | `review_suggested` | any `enabled_missing` entry | Names in plugins.enabled matched no bundled plugin and no plugin folder with a manifest in this home; this compares configuration with disk and does not prove the plugin is unavailable, because entry-point plugins and plugins outside the home are not visible to this check. |
| `dead_stores.orphan_plugin_data` | `info` | any orphan | Folders under plugin-data match no plugin folder, enabled name, or bundled plugin in this home; byte counts measure stored plugin state and do not show whether it will be used again. |
| `dead_stores.regenerable_caches` | `info` | cache total > `REGENERABLE_CACHES_THRESHOLD_BYTES` | Index, model-catalog, media, tool and installer cache files total more than 20 MiB; sizes measure files on disk and do not show whether they will be needed again or what a rebuild would cost. |
| `dead_stores.request_dumps` | `review_suggested` | dump count > `REQUEST_DUMPS_THRESHOLD_COUNT` | More than 10 request_dump files from failed API requests are in sessions folders; counts and sizes measure files on disk and do not show the cause of those failures or any current fault. |
| `dead_stores.unrotated_logs` | `info` | any unrotated log in a Hermes log location | Log files over 500 KiB in Hermes log locations, excluding logs Hermes rotates and files with a rotated sibling, were found; sizes measure those files on disk and do not show errors or a current fault. |
| `dead_stores.backup_file_pile` | `info` | backup-style count > `BACKUP_PILE_THRESHOLD_COUNT` | More than 20 backup-style files were found across the home; backup-style name patterns outside backups/config are not defined by the Hermes source, counts and sizes come from file names and sizes only, credential-named files are counted and never opened, and this does not show whether any copy is still needed. |
| `dead_stores.stale_locks` | `info` | stale zero-byte lock count > `STALE_LOCKS_THRESHOLD_COUNT` | More than 10 zero-byte .lock files have a modification time over 24 hours before the newest file in the home; this measures file timestamps and does not show whether any process holds or waits on a lock. |
| `dead_stores.unreferenced_skill_clones` | `review_suggested` | `external_skill_dirs` known and an unreferenced clone exists | Folders under a top-level vendor-skills style directory are not listed in skills.external_dirs; byte counts measure files on disk and do not show whether anything outside Hermes uses them. |
| `dead_stores.feature_off_assets` | `info` | `pet_enabled` is `False` and `pets/` has bytes | Pet sprite files are on disk under pets while display.pet.enabled is false; byte counts measure those files and do not show a configuration error. |
| `dead_stores.summary` | `info` | total dead weight > 0 | Dead-store classes were measured across the home; class totals and home share are file sizes on disk that overlap bytes counted by other sections, must not be added to other sections' totals, and do not by themselves make any file safe to delete. |
| `dead_stores.could_not_verify` | `info` | any unverified check or cut (`coverage: could_not_verify`) | One or more dead-store sub-checks could not be verified because a configuration value was not supplied, the home could not be read, or a traversal budget was reached; unverified checks are not reported as clean. |
